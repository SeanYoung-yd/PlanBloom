# PlanBloom

PlanBloom 是一款本地优先的日常计划应用。它用轻量、直观、元气的方式帮助用户安排每天的任务、规划每月目标、拆解年度方向，并通过“在月历上贴贴纸”的习惯打卡方式让坚持变得更有趣。

## 关键词

`daily-planner` `habit-tracker` `local-first` `indexeddb` `dexie` `react` `typescript` `vite` `tailwindcss` `planbloom`

## 功能

- 今日概览：今日重点、今日任务、习惯快捷打卡、本月目标进度。
- 日度计划：时间轴、待办清单、任务编辑、随手记。
- 月度计划：月历、月目标、轻量事件、日期摘要。
- 年度计划：年度关键词、时间轴视图、分类目标视图。
- 习惯贴纸：预设贴纸、月历打卡、连续天数和月度统计。
- 总结复盘：月度统计、年度统计、习惯排行、年度报告导出。
- 本地数据：使用 Dexie.js + IndexedDB 保存，无账号、无后端。
